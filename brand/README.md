# Hollis brand guide

## Concept: Continuation

```
  ○        an open ring: the task, still hollow
  │
  └──■     a right-angled path to a solid square: the recorded result
```

Hollis makes agent work durable. Every step is recorded, interrupted work continues where it stopped, and intent becomes an inspectable result. The mark draws exactly that:
- **The ring:** an open task. "Hollow" is a quiet nod to the name.
- **The path:** the run through models, tools and approvals.
- **The square:** the settled, recorded outcome.

The ring and square carry equal visual weight: two states of one piece of work. The sharp corner is the tree connector developers read in terminals and logs every day (`└─`). That gives the mark a natural text form (below), and keeps it on the engineered side of the line rather than the decorative.

**What it deliberately avoids:** robots, brains, sparkles, orbs, chat bubbles, circuit patterns, gradients.

**Alternatives explored and rejected:**
- an H monogram (too generic, and close to existing H marks);
- stacked "log line" bars (reads as a list icon);
- a gate (cultural associations);
- a holly motif (seasonal);
- a rounded elbow version of this mark (read as a key or a pipe).

## Assets

Everything is generated by `brand/build.py` from one geometric definition. Edit the geometry there; never hand-edit outputs.

| File | Use |
|---|---|
| `svg/icon.svg` | **Primary icon**: ink mark on a brass tile. Works on light and dark backgrounds |
| `svg/icon-dark.svg` | Brass mark on an ink tile |
| `svg/icon-small.svg`, `icon-small-dark.svg` | Pixel-aligned 16-unit variant for 16 to 32 px |
| `svg/icon-mono-black.svg`, `icon-mono-white.svg` | One-colour icons |
| `svg/mark-*.svg` | The mark without a tile (ink, paper, brass, black, white, `currentColor`) |
| `svg/wordmark-*.svg` | "hollis" set in IBM Plex Sans SemiBold, tracked −1.2%, i-dot in brass |
| `svg/lockup-*.svg` | Horizontal lockup: icon and wordmark |
| `png/icon-{16..1024}.png`, `png/icon-dark-*.png`, `png/favicon.ico` | Application icons and favicon |

The web app's `public/` gets `favicon.ico`, `favicon.svg`, `apple-touch-icon.png` and the 192 and 512 px icons from the same build.

**Rebuilding:**

```bash
npm pack @fontsource/ibm-plex-sans@5.3.0 && tar xzf fontsource-ibm-plex-sans-5.3.0.tgz
uv run --no-project --with fonttools --with brotli --with pillow python brand/build.py package/files
```

## Usage

- **Clear space:** keep at least half the icon's height clear on every side of the icon and the lockup. Inside the lockup, the gap between icon and wordmark is fixed (0.36 × icon height); don't change it.
- **Minimum sizes:**
  - icon: 16 px (use `icon-small` at 16 to 32 px);
  - mark without tile: 12 px;
  - lockup: 20 px tall;
  - wordmark: 14 px tall.
- **Backgrounds:**
  - On paper and other light backgrounds, use the ink wordmark and the primary icon.
  - On ink and dark backgrounds, use the paper wordmark with the primary or dark icon.
  - On photographs or busy backgrounds, use a mono icon on a solid tile.
- **The i-dot:** brass in the colour wordmark (the result square, set into the name), and the same colour as the letters in mono versions.

### Incorrect use

- Don't rotate, mirror or skew the mark. The path always runs down, then right.
- Don't round the corner of the path, add gradients, glows, shadows or outlines, or animate the mark decoratively.
- Don't recolour the tile outside the palette, or place the brass tile on brass backgrounds.
- Don't rebuild the wordmark in another typeface, or change its letter spacing.
- Don't put the mark inside other shapes (circles, speech bubbles) or combine it with other symbols.

## Colour

Neutrals are warm ink and paper, the ledger the product keeps. One accent, brass, carries the brand. Status colours are separate from it, so "brand" never means "success".

| Token | Light | Dark | Notes |
|---|---|---|---|
| Ink / text | `#17140F` | `#ECE7DD` | Ink on paper: 16.6:1 |
| Paper / background | `#F6F3EC` | `#12110E` | |
| Brass (fill, tile, selection) | `#B8862F` | `#D9A94E` | Ink on brass: 5.7:1. Brass is **not** a text colour on paper (2.9:1) |
| Brass text and focus | `#86621F` | `#D9A94E` | 5.0:1 on paper; 8.8:1 on dark |
| Muted text | `#6B655B` | `#9C9588` | 5.2:1 and 6.4:1 |
| Success | `#2F7D52` | `#5CC08A` | 4.5:1 and 8.4:1 |
| Warning | `#A85414` | `#E8914A` | 4.8:1 and 7.7:1 |
| Danger | `#B4382F` | `#EE7468` | 5.3:1 and 6.6:1 |
| Info | `#355F92` | `#82AEE6` | 5.9:1 and 8.2:1 |

The dark theme isn't an inversion. Surfaces step *up* in lightness for elevation, brass brightens for legibility, and borders carry more of the structure than shadows do.

## Typography

- **IBM Plex Sans** (UI) and **IBM Plex Mono** (identifiers, events, code, numbers in tables). Both are licensed under the SIL OFL 1.1 and self-hosted, so the product never calls a font CDN.
- **Scale:** 12, 13, 14 (body), 16, 20, 24, 32. Weights 400, 500 and 600.
- Mono is for anything a user might copy: ids, paths, arguments, event types.

## In the interface

- The mark appears once in the app chrome, at the top of the navigation. The browser tab uses the small icon.
- Brass is reserved for the primary action, the current navigation item, selection and focus. Never use it for decoration.
- Status uses its own colours, always paired with a word or a shape, never colour alone.
- Pages use borders and alignment for structure, not floating cards. The run timeline borrows the mark's own grammar: steps connected by right-angled rails.

## In the terminal

```
Unicode:  ○       ASCII:  o
          └─■             `-#
```

The CLI prints the two-line mark with `hollis` beside it in `hollis --version` and `hollis init`. It falls back to ASCII when the terminal can't encode Unicode or when `HOLLIS_ASCII=1` is set. Colour is used only on a TTY, and never when `NO_COLOR` is set.

## Similarity

I reviewed the mark against well-known developer and AI brands (Anthropic and Claude, OpenAI, Linear, Vercel, Raycast, HashiCorp, GitHub, GitLab, Temporal, Docker, Postman, Notion) and found no confusing similarity. Generic flow-diagram icons share the vocabulary of connected shapes; the equal-weight ring and square on a brass tile, with a sharp terminal corner, is what distinguishes this mark. **No legal trademark clearance has been performed.**
